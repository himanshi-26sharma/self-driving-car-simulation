# Self-Driving Car Simulation with NEAT

![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)
![Pygame](https://img.shields.io/badge/Pygame-2.6.1-green.svg)
![NEAT](https://img.shields.io/badge/NEAT-Python-orange.svg)

A Python simulation where cars learn to navigate a track using the NEAT (NeuroEvolution of Augmenting Topologies) algorithm.

![Simulation Demo](demo.gif) <!-- Add a demo GIF if available -->

## Features

- 🚗 Autonomous cars with 5 distance sensors
- 🧠 Neural networks that evolve using NEAT algorithm
- 🏁 Customizable racetrack generation
- 📊 Real-time fitness visualization
- ⚡ Pygame-based visualization

## Prerequisites

- Python 3.11+
- Pygame 2.6.1
- NEAT-Python 0.92
- NumPy
